# 2026-06-10 インターバルの多様化と短時間練習のW-up/C-down調整

## 概要
週間練習メニュー生成の `I`（インターバル）セッションに **バリエーション** を追加し、
さらに **練習時間が短いセッションでは W-up / C-down を削除/短縮** するようにした。

## 要望
- 練習のインターバルに「200mのような短いインターバル」や「ビルドアップ走（1kmごとにペースアップ）」などを織り交ぜたい
- 練習時間が短いものは、ウォーミングアップ・クールダウンの時間を無くしたい

## 変更内容（index.html）

### 1. インターバルのバリエーション化（`I_VARIANTS`）
`I` スロットを以下の4種から **曜日インデックス（`dayIdx % 4`）で切り替え**て生成するようにした。
週ごとに練習曜日を変えるとインターバルの内容も変わる。

| key | 表示名 | バッジ/色 | 内容 | 疾走ペース |
|---|---|---|---|---|
| `I1000` | インターバル 1000m | I / 橙 | 1000m × N本（つなぎジョグ） | I（VO₂max） |
| `I400` | インターバル 400m（短） | R / 赤 | 400m × N本（最低4本） | R |
| `I200` | インターバル 200m（短） | R / 赤 | 200m × N本（最低6本） | R |
| `BU` | ビルドアップ走 | B / 紫 | 1kmごとにイージー→M→T へペースアップ | E→T レンジ表示 |

- 短いインターバル（200m/400m）は **R（レペティション）ペース**、本数はメニュー時間から自動算出。
- ビルドアップ走は連続走。平均をおおむねMペースとして距離を概算し、ペース欄は `E → T` のレンジ表示。
- 表示名・バッジ・色はバリエーション側（`displayDef`）で上書き。`s.type` は `'I'` のままなので質練習カウント等の既存ロジックは無改変。

### 2. 短時間練習の W-up / C-down 調整（`trimWuCd`）
全質練習（M / T / I / R / BU）の W-up・C-down を `trimWuCd(wu, cd, minutes)` 経由に統一。

- **30分以下** → W-up / C-down ともに **0分**（本体のみ）
- **30分超** → W-up+C-down の合計が **練習時間の50%を超えないよう比例縮小**（超えなければ規定値のまま）

説明文は `withWuCd(core, wu, cd)` で組み立て、0分の W-up / C-down は文面から省略する。

#### 動作例（VDOT≈44.6 / 目標3:30:00）
- テンポ走 20分 → `テンポ走 約4.3km`（WU/CDなし）
- テンポ走 40分 → `W-up 12分 ＋ テンポ走… ＋ C-down 8分`
- インターバル1000m 30分 → `1000m × 4本`（WU/CDなし）
- インターバル1000m 45分 → `W-up 13分 ＋ … ＋ C-down 9分`（15/10から比例縮小）

## 追加・変更した関数（JS）
- `I_VARIANTS`（新規）: インターバルのバリエーション定義
- `trimWuCd(wu, cd, minutes)`（新規）: 短時間練習のWU/CD削減
- `withWuCd(core, wu, cd)`（新規）: WU/CDを前後に付ける説明文ヘルパー（0分は省略）
- `buildSession(type, minutes, vdot, dayIdx=0)`: 第4引数 `dayIdx` を追加。M/T/I/R を上記ヘルパーに統一
- 呼び出し元 `calculateTraining()`: `buildSession(assign[i], minByIdx[i], vdot, i)` と曜日インデックスを渡すよう変更
