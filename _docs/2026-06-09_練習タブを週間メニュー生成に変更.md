# 2026-06-09 練習タブを「週間練習メニュー生成」に変更

## 概要
練習タブを、従来の「レースタイム→トレーニングペース表（VDOT）」から、
**「目標フルマラソンタイム ＋ 曜日ごとの練習可能時間」→「1週間の練習メニュー自動生成」** に変更した。

## 仕様（ユーザー確認済み）
- 入力方法: **曜日ごとに時間指定**（月〜日それぞれ オン/オフ＋練習時間〔分〕）
- レース本番日（残り期間）の期分け: **考慮しない**（いつでも使える標準週メニュー）
- VDOT・ゾーン別ペース: **メニューに統合**（各練習にペースを併記、VDOTは上部に補助表示）

## 変更内容（index.html）

### HTML（練習カード `#card-training`）
- 「目標フルマラソンタイム」入力（`tr-goal-hour/min/sec`）
- VDOT表示（`#vdot-value`）＋ VDOT解説パネル（流用）
- 「週の練習できる時間」: 7曜日の行（`tr-day-{0..6}-on` チェック / `tr-day-{0..6}-min` 分）
  - idx対応: 0=月, 1=火, 2=水, 3=木, 4=金, 5=土, 6=日
- 「あなたの週間メニュー」: サマリー（`#week-summary`）＋メニュー一覧（`#week-menu`）＋コピーボタン（`#menu-copy-btn`）

### CSS
- `.week-grid / .day-row / .day-toggle / .day-time`（曜日入力UI）
- `.week-summary / .week-menu / .menu-card / .menu-badge / .menu-detail / .menu-pace`（メニュー表示）
- 旧 `.training-zones / .zone-*` は未使用になったが残置（無害）

### JS
- 既存の `calcVdot()` / `vdotToPaceSecPerKm()` を再利用し、フル42.195km＋目標タイムからVDOTを算出
- `ZONE_PCT`（E/M/T/I/R の目標%VO2max）, `SESSION_DEF`（練習種別の名称・色・説明）, `WEEK_TEMPLATE`（練習回数別の構成）
- `buildSession(type, minutes, vdot)`: 1セッションの距離・本数・W-up/C-down・ペース・説明文を組み立て
- `assignSessions(days)`: 練習する曜日に種別を割り当て。最長時間の日をロング走に、質練習(M/T/I)はハード日が連続しないよう分散配置、残りはイージー。練習しない曜日は休養日表示
- `calculateTraining()`: 全面書き換え。曜日の有効/無効でUI（入力欄のdisable、行のdim）も更新
- メニューのテキスト版を `lastMenuText` に保持し、`#menu-copy-btn` でクリップボードへコピー
