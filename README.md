# マラソン準備ツール

ペース換算、タイム予測、週間練習メニュー、ラップ表、コース案、大会カウントダウンをまとめた静的Webアプリです。

公開先は [GitHub Pages](https://tommy780103.github.io/running-pace-calculator/) です。

## 構成

- メイン画面と処理は index.html に集約しています。
- アイコンは青い背景に白いストップウォッチです。iPhone向け180px、ブラウザ向け48px、Webアプリ情報向け192px・512pxを用意しています。
- Webアプリ情報は manifest.webmanifest、OGP画像とアイコンの生成元は _ogp_gen.py です。
- 実装記録は _docs にあります。

## ローカル起動

プロジェクト直下で実行します。

```bash
python3 -m http.server 8765
```

ブラウザで開きます。

```text
http://localhost:8765/
```

## アイコンの確認

iPhoneのSafariで公開ページを開き、共有メニューの「ホーム画面に追加」でストップウォッチ画像が出ることを確認します。以前追加した文字アイコンが残る場合は、そのホーム画面アイコンを削除して追加し直してください。公開側の更新だけで既存アイコンが差し替わるとは限りません。

角丸処理はOSに任せ、PNGは背景を含む不透明な正方形にしています。Webアプリ情報の表示モードは従来のブラウザ利用を保ち、オフライン機能は追加していません。

画像を再生成する場合は、PillowとmacOS標準フォントのある環境で次を実行します（OGP画像も再生成します）。

```bash
python3 _ogp_gen.py
```
