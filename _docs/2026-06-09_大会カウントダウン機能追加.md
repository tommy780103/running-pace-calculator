# 2026-06-09 大会カウントダウン機能の追加

## 概要
目標の大会日を**複数登録**でき、本番までの日数を**カウントダウン**表示する機能を新タブ「大会」として追加した。

## 仕様
- タブナビに「大会」（`event` アイコン）を追加（6タブ目）
- 入力: 大会名（任意・最大50字）＋ 開催日（`<input type="date">`）→「追加」で登録
  - 大会名を空で追加した場合は「大会」を既定名にする
  - 開催日が未入力の場合は追加しない（日付欄にフォーカス）
- 表示: 開催日の昇順でカードを並べ、各カードにカウントダウンと削除ボタン
  - `あと○日`（通常）／ 7日以内は **soon**（CTAカラーで強調）／ 当日は **today**（赤・「本番」）／ 過去は **past**（dim・「○日前・終了」）
- 大会タブを開くたびに `renderRaces()` を再実行し、日付跨ぎでもカウントが最新化される

## 実装（index.html）
### HTML
- タブボタン `data-tab="card-races"` を `card-course` の後に追加
- カード `#card-races`: 追加フォーム（`#race-name` / `#race-date` / `#race-add-btn`）＋ 一覧 `#race-list` ＋ プライバシー注記

### CSS
- `.race-add-row`（入力行・モバイルで折返し）, `.race-list`, `.race-card`(.soon/.today/.past), `.race-info/.race-name/.race-date`, `.race-count .num/.unit`, `.race-del`

### JS
- データ: `races = [{ id, name, date }]`、localStorage キー `pace-calc:v1:races`（JSON）
- `loadRaces()/saveRaces()`: 端末内のみ保存・復元（不正データは空配列にフォールバック）
- `startOfToday()/daysUntil(dateStr)/formatRaceDate(dateStr)`: ローカル日付基準で日数と「YYYY年M月D日（曜）」を算出
- `renderRaces()`: 日付昇順ソート→カード生成。**大会名は `escapeHtml()` でエスケープ**（XSS対策）
- `addRace()/removeRace(id)`: 追加・削除して保存・再描画
- `setupRaces()`: イベント配線（追加ボタン、名前/日付欄のEnter）＋初期ロード。init から呼び出し

## プライバシー方針（維持）
- 登録した大会名・日付は**この端末内（localStorage）にのみ保存**
- URL共有（`buildShareUrl` は `PERSIST_IDS` ベース）にも、外部送信にも**含まれない**
- カード内にもその旨を注記表示

## 検証
- `node --check` でinline JS構文OK
- カウントダウン: 100日後/7日後(soon)/1日後/当日(today)/3日前(past) の状態判定・日付表示を確認
- DOMスタブ＋Nodeで統合テスト: 複数登録(3件)・名前空の既定名・localStorage保存復元・日付未入力時の非追加・削除・**escapeHtmlによる `<img onerror>` の無害化**を確認
- ブラウザでの見た目目視は未実施（既存UIパターン踏襲、構造上は問題なし）

## 補足
- タブが6個になったため、極端に狭い画面では窮屈になる可能性あり（既存の `max-width:600px / 380px` のメディアクエリで縮小対応済み）。実機確認を推奨。
