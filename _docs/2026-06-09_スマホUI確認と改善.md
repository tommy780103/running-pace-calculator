# 2026-06-09 スマホ操作性の全面確認と改善

共有前提でモバイル操作性をコードベースで全面確認した結果と、実施した改善の記録。

## 確認した項目と結果（良好）
- **viewport**: `width=device-width, initial-scale=1.0`。`maximum-scale`/`user-scalable=no` を付けていないためユーザーズーム可（アクセシブル）
- **iOSの自動ズーム回避**: フォーカス対象の入力欄はすべて font-size 16px 以上
  - `.input-field input` 2rem / `.input-select` 1rem / `.day-time input` 1.15rem / `.race-add-row input` 1rem
- **入力キーボード最適化**: 数値欄は `inputmode="numeric/decimal"`、開催日は `type="date"`（ネイティブピッカー）
- **タップで全機能操作可**: hover専用UIは無く、タブ/プリセットは click + 状態クラスで動作
- **横スクロールなし**: `body{overflow-x:hidden}`、結果グリッドは `max-width:600px` で2列化、テーブルはセル padding 縮小
- **タブ固定**: `.tab-nav` は sticky でスクロール中もアクセス可
- **地図**: Leaflet 標準のピンチズーム/ドラッグ対応、高さ340px
- **アニメ抑制**: `prefers-reduced-motion: reduce` 対応
- **主要タッチ要素サイズ**: テーマ切替 44px / アクションボタン 約46px / コースカード・曜日行は十分な padding

## 実施した改善
1. **大会の削除ボタン**: 36px → **40px**、アイコン 20→22px、`:active` フィードバック追加（指で押しやすく）
2. **大会追加フォーム（≤600px）**: 横並び → **縦積み**（大会名・開催日・追加ボタンを各全幅）。狭い画面での `type="date"` の窮屈さを解消
3. **新規UIのモバイル微調整**:
   - ≤600px: `.day-row` padding、`.day-name` サイズ、`.menu-card` padding、`.race-count .num` サイズを最適化
   - ≤380px: タブ文字/アイコンを再調整（6タブ対応）、`.day-time input` を 64px に縮小して曜日行の収まりを改善

## 残る留意点（任意）
- タブが6個になったため、極小幅（≤380px）ではラベル文字が小さめ（アイコンは明瞭で識別可）。さらに最適化するならアイコン主体表示や2段折返しも選択肢
- **実機/エミュレータでの視覚確認は未実施**（ブラウザ自動化の新規タブ作成が `Group not found` で失敗したため）。最終的な見た目はSafari/Chromeのモバイル幅で確認推奨

## メモ
- 改善はCSS（メディアクエリ `@media (max-width: 600px)` / `@media (max-width: 380px)` ）と `.race-del` のみ。HTML構造・JSは変更なし
